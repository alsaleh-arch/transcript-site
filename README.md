# 🎙️ رابط تفريغ الفيديو إلى نص

تطبيق ويب بالعربي: ارفع فيديو أو صوت، خذ التفريغ النصي وملفات ترجمة SRT/VTT.

## نشره مجاناً والحصول على رابط

1. فك ضغط الملف الذي حملته من ChatGPT.
2. افتح [GitHub](https://github.com/new) وأنشئ مستودعًا (Repository) جديدًا وليكن `video-to-text`. يمكنك اختيار Public. **لا ترفع فيديوهاتك أو ملفات خاصة إلى GitHub.**
3. من `Add file` ثم `Upload files` ارفع الملفين `app.py` و`requirements.txt`، ثم احفظ التغييرات بالضغط على `Commit changes`.
4. افتح [Streamlit Community Cloud](https://share.streamlit.io/)، وسجّل الدخول باستخدام GitHub، ثم اختر `Create app` والمستودع الذي أنشأته، واجعل `Main file path` مساويًا `app.py`.
5. اضغط `Deploy`. ستحصل على رابط بعنوان مشابه لـ `https://your-chosen-name.streamlit.app` (هذا مثال فقط وليس رابطًا منشورًا بالفعل).

## تشغيله على الكمبيوتر (اختياري)

```bash
python -m pip install -r requirements.txt
python -m streamlit run app.py
```

افتح العنوان المحلي الذي يظهر، غالبًا `http://localhost:8501`.

## كيف يعمل؟

- يرفع المستخدم ملف فيديو أو صوت. الحد الافتراضي في Streamlit هو **200 MB لكل ملف**.
- يستخرج Whisper الكلام من مسار الصوت داخل الفيديو، ويعطي نصًا قابلاً للتعديل.
- يتيح تنزيل **TXT**، و**SRT**، و**VTT**. ملفات الترجمة مقسمة وفق مقاطع تفريغ النموذج، وقد تحتاج ضبطًا يدويًا للاستخدام الاحترافي.
- يستخدم `faster-whisper` على المعالج CPU بتكميم `int8`، **بدون مفتاح API** أو رسوم لكل دقيقة تفريغ، لكن هناك حدود موارد على الاستضافة المجانية، وقد تتباطأ المقاطع الطويلة.
- النموذج يُنزّل عند أول تشغيل. يُحذف الملف المؤقت الذي أنشأه التطبيق بعد انتهاء المهمة؛ لكن الفيديو يُرسل إلى خادم Streamlit وقد يظل داخل ذاكرة جلسة المستخدم مؤقتًا.
- يدعم ملفات فيديو وصوت شائعة؛ بعض صيغ الترميز قد لا تعمل. لا يفرغ الروابط الخارجية مثل YouTube مباشرة في هذه النسخة؛ المطلوب رفع ملف موجود على جهازك.

## خصوصية

للمقاطع الحساسة، شغّل التطبيق محليًا على جهاز موثوق، ولا تستخدم استضافة عامة. واجهة الويب العامة لا تتضمن تسجيل دخول أو حصة لكل مستخدم؛ لا تستخدمها كخدمة مفتوحة للجمهور بكثافة دون إضافة حماية وحدود استخدام.

## تغيير الدقة

التطبيق يتيح اختيار نموذج `tiny` (سريع) أو `base` (أدق عادة). الدقة تعتمد على جودة الصوت واللغة واللهجة؛ استخدام موديل `small` مع استضافة أقوى قد يساعد لكنه أبطأ وأثقل على الاستضافة المجانية.
